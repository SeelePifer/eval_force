# evalforge-qa-v1

Original support questions for a fictional shop, Northwind. The questions, expected answers, and corpus were written for EvalForge. They are not copied from MMLU, GSM8K, or any other public benchmark.

License: [CC0 1.0](LICENSE).

The canonical dataset hash is SHA-256 of one JSON document with two fields: `cases` and `corpora`. Case objects stay in file order. Each corpus file is included under its path, with chunk objects in file order. Keys are sorted, there is no extra whitespace, and UTF-8 characters are left unescaped.
