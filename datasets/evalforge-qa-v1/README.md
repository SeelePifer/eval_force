# evalforge-qa-v1

Original support questions for a fictional shop, Northwind. The questions, expected answers, and corpus were written for EvalForge. They are not copied from MMLU, GSM8K, or any other public benchmark.

License: [CC0 1.0](LICENSE).

The canonical dataset hash is SHA-256 over the case objects in file order. Each object is serialized with sorted keys, no extra whitespace, and UTF-8 characters left unescaped. Objects are joined with a newline.

The current hash of `cases.jsonl` is `aff59e9a86b6c01342cd242fd17bc47df42cce5c076e9f4fd3feda2287cebf2c`.
